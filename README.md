# Palmetto Laser Creations

Simple one-page website for a South Carolina laser engraving business specializing in custom tiles, coasters, flasks, and bamboo boards.

## Live site
Once connected to the custom domain: **palmettolasercreations.com**

## Local preview
Just open `index.html` in a browser, or serve the folder with any static server.

## Deploy to GitHub Pages
1. Push this folder to the `main` branch of the repository.
2. In the repo settings → Pages → Source: Deploy from a branch → `main` / root (or `/docs` if you prefer).
3. Then add the custom domain `palmettolasercreations.com` in the Pages settings.
4. In Namecheap, point the domain’s A records (or CNAME) to GitHub Pages as instructed.

## Content notes
- The “About” section uses the approved spiel.
- Gallery images are the real product photos supplied.
- Contact email is a placeholder — change it to the real address when ready.
